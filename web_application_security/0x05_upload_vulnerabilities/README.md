# Upload Vulnerabilities

## Description

This project focuses on identifying and understanding file upload vulnerabilities in web applications. It covers common security weaknesses related to unrestricted file uploads, client-side and server-side validation, MIME type manipulation, magic numbers, special characters, and file size restrictions.

The exercises are performed in a controlled lab environment (`Cyber - WebSec 0x05`) to demonstrate how insecure upload mechanisms can be identified and tested safely.

## Learning Objectives

By completing this project, I learned:

- What unrestricted file upload vulnerabilities are.
- Why insecure file uploads are dangerous.
- How file upload forms can be abused.
- The purpose of web shells.
- The role of MIME types in file uploads.
- What Content-Type spoofing is.
- The importance of server-side validation.
- File extension filtering techniques.
- How client-side validation can be bypassed.
- Secure file upload best practices.
- Why limiting file size improves security.
- Risks of storing uploaded files on the same domain.
- How file permissions affect upload security.
- Why upload directories should not allow code execution.
