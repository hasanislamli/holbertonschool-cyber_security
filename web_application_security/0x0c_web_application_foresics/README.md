# 0x0C Web Application Forensics

## Description

This project focuses on web application forensics, log analysis, digital forensics, and incident response.

The goal is to analyze logs generated by attacks, identify attacker activity, determine the services used to gain access, and extract useful forensic information.

## Tasks

### 0. Attacker Service

The objective is to analyze system logs and determine which service attackers used to gain access to the system.

The `0-service.sh` script is used to analyze the logs and identify the service involved in the attack.

The identified service is SSH (`sshd`).
